# Sai Teja & Kreethna — Engagement Invitation

A responsive, single-page invitation website built with plain HTML, CSS and JavaScript.

## Included
- Cinematic dark luxury styling with gold accents
- Mobile-responsive layout
- Event date: 11 November 2026
- Venue: Madhapur, Hyderabad
- Live countdown (automatically switches to a celebration message after the date)
- Google Maps search link for Madhapur, Hyderabad
- User-activated, browser-generated soft instrumental audio (no copyrighted song file)
- Sample remote photography from Unsplash

## Preview locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a **public** repository. For a personal site, name it exactly `YOUR-USERNAME.github.io`. Alternatively, use any repository name and its URL will include `/<repository-name>/`.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root. Keep the filenames unchanged.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and open `https://YOUR-USERNAME.github.io/` (or the repository URL for a project site).

## Customize
- Change names/date/venue in `index.html`.
- Change the countdown date in `script.js`. JavaScript months are zero-based: November is `10`.
- Replace the Unsplash image URLs in `style.css` with your own publicly hosted image URLs, or download your photos into an `assets` folder and use paths such as `assets/couple.jpg`.
- The current audio is an original synthesized motif, not a Telugu film song. To use a specific track, only upload audio you own or have permission to use, then add an audio player in `index.html`.
